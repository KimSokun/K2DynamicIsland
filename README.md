# K2 Dynamic Island

A sleek, modern floating desktop capsule application for Windows 10 and Windows 11.

---

## Overview

**K2 Dynamic Island** provides an unobtrusive, fluid desktop experience designed to streamline your daily workflow. Floating at the top of your screen, it keeps essential controls, media playback status, file inspection, and system metrics right at your fingertips.

---

## Key Features

- **Floating Dynamic Capsule:** Minimalist, compact pill with smooth spring expansion and collapse animations.
- **Audio Activity & Mini-Equalizer:** Real-time audio wave animation synced with your favorite music and video players (Spotify, YouTube, VLC, browser audio).
- **File Drop & Path Inspector:** Easily drop files to inspect filenames, extensions, disk sizes, and copy exact paths to the clipboard with one click.
- **Dynamic Animation Themes:** Choose from built-in character animations (Spider-Verse, Cute Cat, Stitch, Vegeta Ultra Ego, and Sakura Forest).
- **Quick Tools & System Metrics:** Monitor real-time CPU load, RAM usage, and battery status with instant shortcut utilities.
- **Local Reminders:** Organize your daily tasks and reminders stored securely on your local machine.
- **Privacy First:** 100% local and offline operation. No telemetry, no tracking, and no cloud dependencies.

---

## Installation

1. Download the latest installer **`K2DynamicIsland-Setup.exe`** from the [Official Releases](https://github.com/KimSokun/K2DynamicIsland/releases).
2. Run the setup installer and follow the wizard.
3. Launch **K2 Dynamic Island** from your Start Menu or Desktop shortcut.

---

## System Requirements

- **Operating System:** Windows 10 or Windows 11 (64-bit)
- **Runtime:** Microsoft Edge WebView2 Runtime (pre-installed on Windows 10 and 11)
